# FIX-P0-16 probe grid (T013 R15 3 P0 families + grid residuals)

Re-runs the T013 R15 3 P0 families (C3 overreach, nospace
anchor-colon scanner layer, scalar-tag loader boundary) plus the
grid residuals found while fixing them (tagged empty key without
anchor, flow anchored-collection-key, and the `!foo &b:!!str`
(c)-interaction), through two parallel mappings:

- `map-p0-16.py` — parser-level: npm `yaml` YAML.parse vs PyYAML
  `yaml.load` with the Oracle's `_StrictBaseLoader`, plus the
  PyYAML token stream. Groups p1 (C3), p2 (scanner), p3 (loader),
  p4 (residual boundaries).
- `map2-p0-16.py` — end-to-end: the shape grid through the real
  probe drivers (TS bundle + `scripts/oracle-parse-probe.py` /
  `scripts/oracle-jobs-probe.py`, full JSON compare, trigger +
  jobs mode per shape). This is the authoritative count: a
  parser-level difference in an ignored key's VALUE is invisible
  here — only parse status / `on:` / `jobs:` content matter.
- `ast-dump-p0-16.mjs` — npm AST dump confirming the flow
  family mechanism: in a flow mapping the collection following an
  anchor-colon is the pair's KEY (YAMLMap/YAMLSeq, value null),
  so `hasUnrepresentableKey` fires; a scalar following it is a
  scalar key and is accepted.
- `gen-expected-p0-16.ts` — generator for the new test fixtures'
  `expected.json` (TS half; the Oracle half comes from
  `scripts/oracle-parse-probe.py` per fixture).

## Reproduce

From the repo root, after `npm ci`:

    python3 evidence/probes/fix-p0-16/map-p0-16.py [group]
    python3 evidence/probes/fix-p0-16/map2-p0-16.py [group] [--results <path>]
    node evidence/probes/fix-p0-16/ast-dump-p0-16.mjs

`results.json` in this directory is the committed end-to-end
grid (238/238 MATCH, 0 diffs), generated by
`map2-p0-16.py all --results evidence/probes/fix-p0-16/results.json`.
The `map2-*.txt` files are the per-group run transcripts
(pre-fix baselines, intermediate states, and the final runs).
